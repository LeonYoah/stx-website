# STX 45 秒宣传片 · 分镜脚本

## 基本信息

| 项 | 内容 |
| :--- | :--- |
| 时长 | 45 秒 |
| 规格 | 1920×1080，30 fps，H.264 + AAC；另有 3840×2160 母版 |
| 受众 | 在生产环境跑 Apache SeaTunnel 的数据平台、运维工程师 |
| 核心信息 | **让 SeaTunnel 运维清晰可见** |
| 行动号召 | 一行命令安装 · GitHub · 在线体验 |
| 投放场景 | 官网产品介绍、发布会 / Meetup 开场、B 站 / 视频号 |

创意、视觉母题与 [30 秒版](../stx-30s/STORYBOARD.md) 一致：**从「黑箱」到「清晰可见」**，扫描线贯穿全片。

## 与 30 秒版的区别

| 项 | 30 秒版 | 45 秒版 |
| :--- | :--- | :--- |
| 能力章节 | 6 个 | 7 个：安装包与插件、版本升级各自成章，Checkpoint 增加历史快照 |
| 每章时长 | 3.2 – 3.6 秒 | 4.8 秒（3 小节） |
| 镜头 | 每章一到两个动作 | 每章都有镜头推近或光标点击，界面停留更久 |
| 配乐 | 律动一路到底 | AI Agent 章节第一小节为间奏，用户输入完毕时重新落拍 |

## 结构

| 段落 | 时间码 | 作用 |
| :--- | :--- | :--- |
| 痛点 | 0:00.0 – 0:03.6 | 制造共鸣：运维像黑箱 |
| 品牌 | 0:03.6 – 0:06.8 | 标志 + Slogan |
| 能力 ×7 | 0:06.8 – 0:40.4 | 主机集群、安装包插件、工作台、Checkpoint、告警诊断、版本升级、AI Agent |
| 收尾 | 0:40.4 – 0:45.0 | 安装命令 + 链接 |

150 BPM，一小节 1.6 秒。品牌落在 3.6 秒，之后每个切镜都落在小节线上。

## 声音设计

| 项 | 说明 |
| :--- | :--- |
| 速度 / 调性 | 150 BPM，A 小调；进行 Am – F – C – G，结尾解决到 C 大调 |
| 对齐 | 品牌冲击 3.6 秒、律动落点 6.8 秒、间奏 35.6 – 37.2 秒、收尾冲击 40.4 秒；每次切镜都有扫光 whoosh 和镲片 |
| 音效 | 高亮、光标点击、镜头推拉、打字、打勾、「已下载」都有对应提示音，由时间线导出的提示点驱动 |
| 响度 | 约 -15 LUFS，真峰值低于 -1.5 dBFS |

当前配乐是程序合成的临时配乐。正式投放前可换成授权音乐：选 150 BPM 左右、3.6 秒和 37.2 秒处有重音的曲目，保留音效层即可。

## 重新截图

截图由 `promo/capture.mjs` 从演示环境 [demo.stxcli.com](https://demo.stxcli.com) 拍摄。账号密码只通过环境变量传入，不写进任何文件。

```bash
STX_UI_USER=<账号> STX_UI_PASSWORD=<密码> pnpm promo:capture

# 只重拍部分镜头
STX_UI_USER=<账号> STX_UI_PASSWORD=<密码> node promo/capture.mjs --only plugins,packages

# 先看构图：1 倍 JPEG 输出到 promo/assets/_explore/，并画出记录的元素框
STX_UI_USER=<账号> STX_UI_PASSWORD=<密码> node promo/capture.mjs --preview
```

| 变量 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `STX_UI_URL` | `https://demo.stxcli.com` | Web UI 地址 |
| `STX_UI_USER` / `STX_UI_PASSWORD` | 无 | 登录账号 |
| `STX_UI_TZ` | `Asia/Shanghai` | 截图里的时间按该时区显示 |

截图脚本只读：浏览器里除少量只读查询接口外，所有非 GET 请求都会被拦截，不会在演示环境里下载插件、创建任务或触发升级。镜头清单在 `promo/shots.mjs`。

## 制作与渲染

| 文件 | 作用 |
| :--- | :--- |
| `index.html` | 本版的功能镜头：窗口、裁剪、高亮 |
| `timeline.js` | 镜头时间码、每镜动作、配乐间奏 |
| `../shared/kit.js` / `../shared/promo.css` | 共用场景（痛点、品牌、AI Agent、收尾）、动效与样式 |
| `../render.mjs` | 逐帧渲染（Chrome + ffmpeg，无 npm 依赖） |
| `../soundtrack.py` | 按提示点生成临时配乐与音效（仅依赖 numpy） |

环境要求与 30 秒版相同：Node ≥ 22、Chrome / Chromium、ffmpeg、Python 3 + numpy，站点根目录已执行 `pnpm install`，系统装有 Inter、Noto Sans CJK SC、JetBrains Mono 字体。

```bash
# 浏览器预览：直接打开 promo/stx-45s/index.html（空格暂停，←/→ 逐帧，R 重播，?t=20.5 定格）

# 一条命令出片：导出提示点 → 生成配乐 → 渲染并混音
pnpm promo:45s
# 成片：promo/stx-45s/out/stx-promo-45s.mp4（1080p）、stx-promo-45s-4k.mp4（4K 母版）

# 只导出几帧静帧检查构图（2 倍像素 PNG）
node promo/render.mjs stx-45s --stills 9,20.5,33.6

# 1 倍快速草稿
node promo/render.mjs stx-45s --scale 1

# 导出官网用的网页版（AV1 WebM + H.264 MP4 + 海报），写入 static/video/
pnpm promo:web
# 换海报帧：node promo/export-web.mjs stx-45s --poster 9.1
```

调整镜头时长时，同时修改 `timeline.js` 顶部的时间码和本文的分镜表。

## 官网首页

首页第二屏「45 秒看懂 STX」播放的就是本片，首屏「观看视频」按钮会滚动过去并开始播放。

| 文件 | 作用 |
| :--- | :--- |
| `static/video/stx-promo-45s.webm` / `.mp4` | 网页版视频，`pnpm promo:web` 生成 |
| `static/video/stx-promo-45s-poster.webp` | 海报，点击播放前只加载这张图 |
| `static/video/stx-promo-45s.en.vtt` | 英文字幕，英文首页默认打开；画面文案改动后手动同步 |
| `src/components/home/promoVideo.ts` | 章节起点与上线日期；改了 `timeline.js` 的时间码要同步改这里 |

重新出片后的顺序：`pnpm promo:45s` → `pnpm promo:web` → 核对章节时间与英文字幕 → 更新 `promoVideo.ts` 里的 `uploadDate`。
