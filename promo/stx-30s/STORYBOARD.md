## 创意

**从「黑箱」到「清晰可见」。**

1. 开场是满屏的 ssh、tail、scp 和红色报错，代表今天的 SeaTunnel 运维。
2. 混乱被压缩成一道光，光线展开后出现青鸾标志。
3. 六个镜头依次展示 Web UI 的真实界面。
4. 收尾落在一行安装命令上。

贯穿全片的视觉母题是**扫描线**，来自 STX 登录页的扫描动效。它负责开场收束、品牌展开和镜头切换。

## 声音设计

| 项 | 说明 |
| :--- | :--- |
| 速度 / 调性 | 150 BPM，A 小调；进行 Am – F – C – G，结尾解决到 C 大调 |
| 对齐 | 品牌冲击 3.6 秒、律动落点 6.4 秒、收尾冲击 26.4 秒；每次切镜都有扫光 whoosh 和镲片 |
| 音效 | 高亮、光标点击、镜头推拉、打字、打勾、「已下载」都有对应提示音，由时间线导出的提示点驱动 |
| 响度 | 约 -15 LUFS，真峰值低于 -1.5 dBFS |

当前配乐是程序合成的临时配乐，用来锁定节奏。正式投放前可以换成授权音乐：选 150 BPM 左右、3.6 秒处有重音的电子 / 科技类曲目，保留音效层即可。

## 制作与渲染

成片由 `index.html` 合成：所有动效挂在同一条 GSAP 时间线上，渲染器逐帧定位并截图，再交给 ffmpeg 编码。30 秒版和 45 秒版共用 `promo/shared/` 与渲染、配乐脚本。

| 文件 | 作用 |
| :--- | :--- |
| `index.html` | 本版的功能镜头：窗口、裁剪、高亮 |
| `timeline.js` | 镜头时间码与每镜动作 |
| `../shared/kit.js` / `../shared/promo.css` | 共用场景（痛点、品牌、AI Agent、收尾）、动效与样式 |
| `../render.mjs` | 逐帧渲染（Chrome + ffmpeg，无 npm 依赖） |
| `../soundtrack.py` | 按提示点生成临时配乐与音效（仅依赖 numpy） |

环境要求：Node ≥ 22、Chrome / Chromium、ffmpeg、Python 3 + numpy，并已在站点根目录执行过 `pnpm install`（用到站点已有的 `gsap`）。系统需安装 Inter、Noto Sans CJK SC、JetBrains Mono 字体。

```bash
# 浏览器预览：直接打开 promo/stx-30s/index.html（空格暂停，←/→ 逐帧，R 重播，?t=12.5 定格）

# 一条命令出片：导出提示点 → 生成配乐 → 渲染并混音
pnpm promo:30s
# 成片：promo/stx-30s/out/stx-promo-30s.mp4（1080p）、stx-promo-30s-4k.mp4（4K 母版）

# 只导出几帧静帧检查构图（2 倍像素 PNG）
node promo/render.mjs stx-30s --stills 8.2,12.6,15.6

# 1 倍快速草稿
node promo/render.mjs stx-30s --scale 1
```

调整镜头时长时，同时修改 `timeline.js` 顶部的时间码和本文的分镜表。
