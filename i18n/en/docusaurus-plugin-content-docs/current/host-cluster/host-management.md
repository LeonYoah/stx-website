This guide covers host registration, the agent installation command, heartbeats, and common connection checks.

## At a glance

- Register a physical or virtual machine in the Web UI.
- Run the generated stx-agent installation command on that machine.
- An online host can be used to discover SeaTunnel processes or install a cluster.
