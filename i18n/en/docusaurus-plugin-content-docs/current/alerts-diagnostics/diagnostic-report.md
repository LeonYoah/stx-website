Open **Alerts & Diagnostics → Diagnostics Center → Inspection**, select a report, and choose **Full Report**. Under **Diagnostic Bundle**, open **Preview Report** or **Download Diagnostic Bundle** after collection succeeds.

The report includes an overview, findings, timeline, metrics, collected evidence, and an appendix. A single metric sample is not displayed as a trend; missing samples break the line. Configuration previews have credentials redacted, but review the full bundle before sharing it.
