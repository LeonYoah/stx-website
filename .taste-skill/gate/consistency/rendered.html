产品能力

主机、集群、任务与诊断同在一处

在 Web UI 中查看首页大盘、管理集群与作业、处理告警并发起诊断，运维操作集中完成。

01

首页大盘

先看全局，再落到问题本身。

  • 集群、作业与主机状态同屏呈现
  • 关键指标与异常入口就近可达
  • 从概览进入告警、巡检与作业详情

02

集群生命周期

安装、启停、一键升级，不再散落在脚本里。

  • 创建到升级的完整链路同屏管理
  • 节点可配置自定义 JDK
  • 端口和 JVM 堆内存在安装配置里指定

03

调试工作台

草稿保存、版本发布，形成可回看的闭环。

  • 保存只更新草稿；发布新版本后才能正式运行
  • Savepoint 恢复前会提示先发布版本
  • HOCON 与 Checkpoint 可逐层排查

04

测试连接

改完地址与表名，先探活再跑作业。

  • 工具栏一键测试连接，不必先发布
  • 验证库能否连通、对象是否存在
  • 失败先改配置，再继续 DAG 或预览

05

作业 DAG 拓扑

配置落成图，上下游一眼能对上。

  • 从 HOCON 解析出执行拓扑
  • Source 与 Sink 的表路径同屏可见
  • 点开算子即可看上下游与表结构

06

实时可观测

运行水位实时可见，异常有据可查。

  • 作业吞吐与运行态同屏刷新
  • 监控承接水位信号，便于下钻
  • 确认后可继续走到诊断与恢复

07

作业告警

告警进入 AlertHub，处理路径清晰。

  • 作业告警事件集中呈现
  • 规则与通知通道可配置
  • 确认、静默后可转入诊断
