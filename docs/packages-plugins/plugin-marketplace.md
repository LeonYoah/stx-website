Web UI **安装包与插件** → **插件市场**（`/plugins`）。用来浏览连接器、把 JAR 与所需 **附属依赖** 下载到运行 **STX Server** 的机器，再安装到指定集群的各节点。

![插件市场：可用插件与筛选](/img/screenshots/07-plugins.png)

同一入口顶部可切回[安装包管理](./package-management)。工作台里的连接器模板读的是**集群上已装好的插件**；缺 JAR 时先在本页下载并安装到集群。

## 可用插件与本地插件

| 页签 | 做什么 |
| :--- | :--- |
| **可用插件** | 从官方目录浏览连接器；按名称搜索，按 SeaTunnel 版本、分类、镜像筛选 |
| **本地插件** | 已下载到本机的 JAR；可安装到集群或删除 |

页头提供 **一键下载全部**、**刷新连接器**（可用插件）或 **刷新**（本地插件）。下载走当前选中的镜像源；目录刷新仍来自官方 Maven 元数据。

| 卡片上常见信息 | 说明 |
| :--- | :--- |
| **名称 / 分类 / 版本** | 连接器标识与适用的 SeaTunnel 版本 |
| **安装准备** | **无需额外依赖**、**需选择场景**、或 **自动依赖已就绪** |
| **下载 / 安装** | 未落地时先下载；已在本地时可直接安装到集群 |

Transform 类能力一般打在 SeaTunnel 安装包内的 `seatunnel-transforms-v2.jar` 里，**不必在插件市场单独下载**。

## 附属依赖（一键带上驱动）

不少连接器除了自身 JAR，还要 JDBC 驱动等附属库。打开插件详情，切到 **附属依赖**：

| 情况 | 怎么做 |
| :--- | :--- |
| 卡片上写 **需选择场景**（如 Jdbc） | 在 **选择数据源场景** 里勾选 MySQL、Oracle 等，系统自动附带对应依赖，再点 **下载** |
| 卡片上写 **自动依赖已就绪**（如 Hive） | 可直接查看 **当前生效的系统标准依赖**，确认后 **下载** |
| 官方模板盖不住的特殊版本 | 切到 **自定义驱动** 自行补充；需要时可先禁用系统标准依赖 |

![Jdbc：选择数据源场景后自动附带依赖](/img/screenshots/25-plugin-deps-profile.png)

![Hive：自动依赖已就绪时可直接下载](/img/screenshots/26-plugin-deps-ready.png)

勾选场景后，列表会列出 **场景驱动** 的 Group ID、Artifact ID、版本和目标目录（如 `plugins/connector-hive`）。下载时会把连接器与这些依赖一并落到本机，安装到集群时一并推送。

## 先下载，再装到集群

典型顺序：

1. 在 **可用插件** 选好 SeaTunnel **版本**（与目标集群一致）。
2. 若提示 **需选择场景**，先在 **附属依赖** 里选好数据源场景。
3. 点 **下载**；进度可在 **本地插件** 查看。
4. 在 **本地插件** 点 **管理插件** / **安装到集群**，选择版本匹配的集群。
5. 若含 `lib` 类依赖，界面可能提示安装后 **立即重启** 集群。

| 落盘位置 | 默认 |
| :--- | :--- |
| 插件缓存 | `./lib/plugins`（相对 STX Server 工作目录） |

安装到节点后，连接器 JAR 进入节点 SeaTunnel 目录下的 `connectors/`，部分依赖进入 `lib/` 或对应 `plugins/` 子目录。节点上的 **stx-java-proxy** 会加载这些 JAR，供工作台探测表结构等。

集群详情里的 **已安装插件** 可查看、卸载；也可从那里跳回本页继续添加。一键安装向导里也可勾选要随集群安装的插件。

## 本地插件列表

| 列 | 说明 |
| :--- | :--- |
| **插件名称 / 分类 / 版本** | 已缓存的连接器 |
| **已安装集群** | 哪些集群已装上该插件 |
| **文件大小** | 本地 JAR 大小 |
| **操作** | **管理插件**（安装）、**删除**（可选同时从所选集群卸载） |

支持勾选后 **批量安装**。空列表时按提示从 **可用插件** 先下载。

升级集群前，目标版本所需插件也需已在本地备齐；缺插件时界面会提示前往插件市场。集群启停与升级见[集群管理](../host-cluster/cluster-management)；作业侧用法见[调试工作台](../workbench/overview)。
