Web UI **告警与诊断** → **告警中心**（`/monitoring`）。同页可切 **诊断中心**、**策略中心**。

![告警中心列表](/img/screenshots/05-monitoring.png)

## 列表

| 列 | 说明 |
| :--- | :--- |
| **集群 / 来源** | 受管集群；来源为 **本地进程事件** 或 **远程 Alertmanager** |
| **告警名称** | 可读名 + 规则标识 |
| **严重级别** | 警告 / 严重 等 |
| **当前状态** | 触发中 / 已恢复 / 已关闭 |
| **摘要 / 时间** | 一句话说明；首次触发、最近变化 |

可按状态、时间、集群、来源筛选，或搜名称 / 规则标识 / 摘要。

## 状态

| 维度 | 取值 | 含义 |
| :--- | :--- | :--- |
| **告警状态** | 触发中 / 已恢复 / 已关闭 | 条件是否仍满足 |
| **处理进度** | 待处理 / 已接手 / 已静默 | 人工处理进度 |

已接手 ≠ 已恢复。

## 操作

| 动作 | 说明 |
| :--- | :--- |
| **确认** | 标记已接手，可写备注 |
| **静默** | 触发中且未静默时可静默一段时间（常见 30 分钟） |
| **人工关闭** | 本次事件不再通知；新事件仍可再告警 |
| **前往诊断中心** | 继续排查，见 [错误中心](./error-center) |

## 策略中心

当前可配置的对外通知：

| 类型 | 怎么发 |
| :--- | :--- |
| **邮件** | SMTP |
| **Webhook** | `POST` JSON 到你填的地址 |
| **企业微信** | 群机器人 Webhook，文本消息 |
| **钉钉** | 同上 |
| **飞书** | 同上 |

企微 / 钉钉 / 飞书按各平台文本格式推到机器人 URL，不是完整 IM 应用对接。渠道「密钥」字段会保存，当前发送未做加签。SMTP 连接测试仅邮件；各类型都可测试发送。

再配统一告警策略（范围、级别、冷却、接收对象）；按集群可调告警规则开关与阈值。

## CLI

```bash
stx monitoring alert list
stx monitoring alert ack <id> --note "已排查" --confirm
stx monitoring alert silence <id> --duration-minutes 30 --confirm
stx monitoring alert-policy list
```
