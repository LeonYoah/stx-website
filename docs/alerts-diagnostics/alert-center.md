在 Web UI 打开 **告警中心**（`/monitoring`）。右上角可切换 **告警**、**规则**、**通知**；左上角可进入[诊断中心](./error-center)。

## 告警事件

![告警列表、状态筛选和时间范围](/img/screenshots/18-alert-events.png)

按状态、范围、级别、集群或时间筛选，也可按名称、规则键或集群搜索。点一条告警查看详情和时间线，用行末 **更多** 菜单处理。

| 操作 | 结果 |
| :--- | :--- |
| **确认** | 标记已接手，不代表问题已恢复。 |
| **静默 30 分钟** | 暂停本次告警的通知，不改变触发条件。 |
| **关闭** | 关闭本次事件；后续仍可能触发新的告警。 |

## 配置告警规则 {#rules}

切到 **规则**，先选 **集群级** 或 **作业级**，再点规则打开详情。

![集群级规则列表、全局默认和启用开关](/img/screenshots/44-alert-policies.png)

- **集群级**：在 **全局默认** 设置规则开关、级别与适用的阈值和持续时间。只改一个集群时，先选该集群再编辑覆盖值；未修改的字段继续沿用全局默认。规则可沿用默认通知，也可指定渠道和接收人。
- **作业级**：按作业管理规则，例如运行失败或 CDC 延迟过高。

## 设置通知与查看投递

切到 **通知**。在 **默认通知** 设置共用渠道、接收人、冷却时间，以及恢复时是否通知。

![默认通知、通知渠道和新建入口](/img/screenshots/19-notification-channels.png)

在 **通知渠道** 点 **新建渠道**，选择邮件、Webhook、企业微信、钉钉或飞书；在渠道列表点 **测试** 检查配置。

![投递记录列表与失败原因](/img/screenshots/45-delivery-history.png)

切到 **投递记录**，按通知渠道、投递状态或事件筛选；投递失败时查看响应和错误。需要继续排查时，转到[巡检与诊断报告](./diagnostic-report)。

命令行操作见 [STX CLI：告警与监控](../architecture/cli#告警与监控)。
