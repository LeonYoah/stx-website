Web UI **告警与诊断** → **诊断中心** → **巡检**（`/diagnostics?tab=inspections`）。在这里查看检查记录，再进入报告。

## 发起巡检

![巡检页的检查记录与入口](/img/screenshots/22-inspection-records.png)

1. 在页面上方选择要检查的集群，点击 **立即巡检**。
2. 设置**巡检时间范围**（5～1440 分钟，默认 30 分钟）、**错误触发阈值**（1～1000，默认 1），选择本次采集资源。
3. 发起后，在检查记录中查看状态、发现项摘要和回溯窗口。点 **摘要** 看本次检查，或点 **完整报告** 打开巡检详情。

巡检会先生成检查记录，再按所选资源启动诊断包采集。如果采集任务启动失败，巡检报告仍可能已经生成；以检查记录和任务状态为准。

![巡检详情中的诊断包状态、执行日志和报告入口](/img/screenshots/23-inspection-detail.png)

巡检详情中的 **诊断包** 区域显示采集状态。可点 **查看执行日志** 核对步骤；任务成功后点 **预览报告** 打开 HTML，或点 **下载诊断包** 保存日志等文件。已经有诊断包时可 **重新生成**；有发现项但尚无诊断包时可选择 **一键生成诊断包和诊断报告**。

## 阅读 HTML 报告

![离线诊断报告总览与左侧页签](/img/screenshots/17-diagnostic-report-overview.png)

| 页签 | 内容 |
| :--- | :--- |
| **总览** | 本次检查的时间范围与发现项摘要。 |
| **需关注的证据** | 按发现项查看观测值及关联证据。 |
| **时间线** | 按时间查看采集期间的事件。 |
| **指标** | 按指标和实例查看采样值、阈值及趋势；单个采样点不画趋势，采样缺口处曲线断开。 |
| **原始证据** | 分类查看错误、巡检、配置、指标、线程栈、告警和进程信息。配置文件可切换查看，预览中的凭证已遮盖。 |
| **附录** | 查看任务、执行步骤和集群信息。 |

“本次未生成结构化发现项”只表示**本次时间范围内已执行的检查**没有产生发现项，不代表没有采集到原始信息。到 **原始证据** 看现场内容；未执行或失败的步骤到 **附录** 核对。

报告左下角可切换浅色或暗色模式。需要 PDF 时，使用 **打印 / 导出 PDF**。HTML 之外的日志、线程栈等文件请从巡检详情下载**诊断包**。分享前检查主机地址、日志和配置内容；配置预览遮盖凭证不代表整个诊断包都可以公开。

从错误线索开始排查见[错误中心](./error-center)；已有处理方法见[排障经验库](./troubleshooting-memory)。
