Web UI **告警与诊断** → **诊断中心** → **经验库**。

![经验库中的处理方法](/img/screenshots/21-troubleshooting-records.png)

## 查看记录

| 类型 | 说明 |
| :--- | :--- |
| **内部经验** | 本环境记录的处理方法 |
| **系统内置** | 产品预置（如 CPU 过高） |
| **错误日志** | 挂在 ERROR 指纹上 |
| **监控告警** | 挂在告警类信号上 |

卡片含标题、触发条件或异常摘要、**已验证排障方案**，以及根因、防范建议、标签等。

## 查找与记录

- **错误**页出现 **已有方案** → 打开对应经验按步骤处理。
- 搜索：标题、指纹、关键词、标签、记录人。
- 新问题解决后点 **新建方案**，写入可复用步骤。

命令行创建或更新记录见 [STX CLI](../architecture/cli)。
