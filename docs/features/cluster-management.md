本文介绍如何在 STX 控制台上纳管现有的 SeaTunnel 集群，或快速部署一个全新的 Zeta 集群。

## 场景选型

STX 支持两种集群管理模式：

| 管理方式 | 适用场景 | 说明 |
| :--- | :--- | :--- |
| **纳管现有集群** | 服务器上已有运行中的 SeaTunnel 集群 | 安装 Agent 后自动探测识别进程，无缝纳管 |
| **一键全新安装** | 全新机器环境，需要快速初始化一套集群 | 在控制台选择机器与安装包版本，全自动安装分发 |

---

## 方式一：纳管已有集群

如果你的机器上已经安装并运行了 SeaTunnel：

1. **进入集群列表**：在左侧导航点击 **「集群管理」**。
2. **点击「纳管已有集群」**：
   * 选择已在线的主机节点。
   * 填写 SeaTunnel 根目录路径（例如 `/opt/seatunnel`）。
3. **点击「自动扫描」**：
   * STX 会调用主机上的 Agent 探测是否存在 `SeaTunnelServer` 或 `SeaTunnelClient` 进程。
   * 扫描成功后，系统自动读取节点的版本号（如 `2.3.8`）并完成注册。

---

## 方式二：一键全新部署集群

通过 STX 的安装向导从零部署新集群：

### 步骤 1：选择目标主机
在部署向导中，勾选需要部署的机器节点：
* 指定 1 台作为 **Master 节点**。
* 指定其余节点作为 **Worker 节点**。

### 步骤 2：选择安装包版本
从已下载的官方安装包列表中选择目标版本（例如 `apache-seatunnel-2.3.8-bin.tar.gz`）。如未提前下载，可在控制台「安装包管理」中一键从官方镜像拉取。

### 步骤 3：提交安装并查看进度
点击「开始安装」，系统后台将自动执行：
1. 分发安装包至所有目标节点的临时目录。
2. 校验文件完整性并解压至目标安装路径。
3. 根据所选角色自动写入 `hazelcast.yaml` 集群发现配置。
4. 启动主节点与工作节点进程。

---

## 集群日常运维操作

在集群详情页面中，你可以执行以下日常操作：

| 操作 | 动作说明 | 影响范围 |
| :--- | :--- | :--- |
| **启动节点** | 通过 Agent 执行 `seatunnel-cluster.sh -d` 启动后台进程 | 离线节点恢复上线 |
| **停止节点** | 发送优雅停机信号终止进程 | 节点下线，作业发生故障转移 |
| **滚动重启** | 逐台重启 Worker 节点，保障集群整体不中断 | 减少对进行中同步作业的影响 |
| **查看日志** | 在线实时查看 `seatunnel-engine-server.log` | 快速排查同步异常 |

:::tip 注意事项
在执行「停止集群」前，请确保所有关键的数据同步 Job 已经处于保存点（Savepoint）或已暂停，避免数据丢单。
:::
